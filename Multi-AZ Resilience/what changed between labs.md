The previous lab used aws ec2 run-instances to launch instances directly, which is a bit more manual. This lab removes the run-instances block and replaces it with Auto Scaling Groups. This means that if an instance fails a health check, the ASG will automatically launch a replacement. This makes it so that the system can heal itself instead of requiring a person to come over and restart the server if something crashes. The lab also creates an Application Load Balancer with two listeners and two target groups which reference the templates from last lab.
