Root user MFA and least-privilege IAM users are matter for cloud security because they reduce the risk of getting your account compromised. The root account has complete access to everything, so protecting it with multi-factor authentication adds a layer of defense against unauthorized access. Additionally, least-privilege IAM users should receive only the permissions necessary to perform specific tasks. This limits what an attacker can do to the account if it is compromised. Essentially, enabling MFA and least-privilege strengths cloud security by protecting the admin account while also minimizing risk and unauthorized access across the environment.
