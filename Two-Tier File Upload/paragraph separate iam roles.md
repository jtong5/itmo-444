The uploader and viewer use separate IAM roles because they need to follow the principle of least privilege. This means that they should only need the necessary permissions to do their task. So for example, the uploader role only grants the permissions needed to write or upload data, while the viewer role only grants read access. If you combine them into one shared role, it would give the user both their permissions which can increase the chance of compromised data or make accidents more frequently. Keeping them separate can also make it easier to manage users and workloads based on their responsibilities.
