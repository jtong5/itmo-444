Environment files like .env are excluded from Git because they can contain sensitive information, such as API keys, passwords, database credentials, etc. This is still the case even in a private repository because the credentials can be accidentally exposed through repository history as well as bots that scan for secrets. The repository could also become public later or could be compromised. In this lab, it is excluded because it contains AMI IDs and security group IDs as well as other secrets that can expose how your is configurated.
